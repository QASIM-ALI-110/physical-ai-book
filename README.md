# Physical AI & Humanoid Robotics Textbook

This project contains the source code and content for the "Physical AI & Humanoid Robotics" textbook, built with Docusaurus.

## Project Overview

This textbook teaches students to bridge the gap between the digital brain (AI Agents) and the physical body (Robots) following a 4-module curriculum:

1. **Module 1**: The Robotic Nervous System (ROS 2)
2. **Module 2**: The Digital Twin (Gazebo & Unity)
3. **Module 3**: The AI-Robot Brain (NVIDIA Isaac)
4. **Module 4**: Vision-Language-Action (VLA) & Capstone

## Hardware Requirements

- **Simulation**: High-Performance Workstations (NVIDIA RTX 4070 Ti+)
- **Edge Inference**: NVIDIA Jetson Orin Nano
- **Robots**: Unitree Go2 or G1 Humanoids

## Technology Stack

- **Framework**: Docusaurus (Classic Preset)
- **Environment**: Python `uv` for backend scripts; Node.js for frontend
- **Content**: Markdown (`.md` or `.mdx`) files organized by Module/Week in the `docs` folder

## Development Principles

This project follows the Physical AI & Humanoid Robotics Constitution which emphasizes:

- Strict syllabus adherence to the 4-module structure
- Hardware realism in all coding examples
- Modular architecture for future integrations
- Test-first approach with practical exercises
- Visionary technical approach emphasizing human-agent-robot partnerships
